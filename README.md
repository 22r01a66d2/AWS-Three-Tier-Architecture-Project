# AWS Three-Tier Architecture Deployment

## Overview

This project demonstrates the deployment of a secure, highly available Three-Tier Architecture on AWS.

The infrastructure separates the application into:

- Web Tier
- Application Tier
- Database Tier

using public and private subnets across multiple Availability Zones.
